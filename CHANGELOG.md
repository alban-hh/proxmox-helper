# Changelog

## 0.1.0

First public cut.

- Shared library under `lib/` for output, packages, services, GitHub
  releases, Docker and Proxmox host helpers.
- 28 addons that run inside an LXC container and 3 tools that run on the
  Proxmox host.
- `pxh` launcher with `list`, `run`, `update` and `update-all`.
- Smoke tests and CI with shellcheck and shfmt.
